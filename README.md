# QQ飞车 3D：十一城 & 秋名山 (QQ Speed 3D)

**在线即玩地址 (GitHub Pages)**：https://dyc19991225.github.io/qq-speed-3d/

基于 **Three.js + TypeScript + WebAudio** 零外部资产纯代码打造的街机 3D 竞速漂移游戏，硬核还原《QQ飞车》核心进阶操作手感（`CWW 喷` / `WCW 喷` / `段位双喷` / `超级起步`）与经典双地图。

## 核心特性

### 1. 三台经典座驾（差异化极速与集气手感）
- **经典雷诺 · Renault**（A 级重装经典）：稳重抗撞，CWW 极限 **312 km/h**，十一城与秋名山全能神车。
- **S-追光剃刀 · Razor**（S 级流线超跑）：超高集气效率与爆发力，CWW 极限 **318 km/h**。
- **经典板车 · Rookie**（情怀初心神车）：轻巧纯粹，老玩家梦开始的地方。

### 2. 正统飞车进阶漂移与喷射状态机
- **车头与速度矢量解耦侧滑物理**：支持入弯甩尾集气、反向点漂 **断位拉车头（段位双喷）**。
- **完整氮气连喷体系**：精准支持 `双喷`、`CW 喷`、`WCW 喷` 与极限 **`CWW 喷`**，配备起跑倒计时黄金时机 **超级起步**。
- **两条立体赛道**：还原 **十一城（City 11 连续发卡弯）** 与 **秋名山（Akina Mountain 五连发卡下坡与捷径）**。

### 3. GameFeel 3D 声画打击感升级
- **GDC `Trauma²` 三轴平滑旋转震屏**：撞墙与开启 CWW 氮气突破时触发电影级旋转震屏与广角 FOV 速度拉伸；
- **144Hz 帧率无关指数阻尼镜头**与加色混合胎火粒子；
- **零 MP3 程序化 WebAudio 声浪引擎**：五挡齿比连续锯齿波转速声浪、`1950Hz` 带通漂移胎啸与氮气涡轮喷射轰鸣。

## 本地运行与构建

```bash
npm install
npm run dev
npm run build
```
